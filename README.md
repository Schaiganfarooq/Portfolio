# Portfolio — Schaigan Farooq

Personal portfolio website of **Schaigan Farooq**, UI/UX Designer.

A clean, responsive single-page site built with vanilla HTML, CSS, and JavaScript —
featuring a light/dark theme, scroll-reveal animations, and a fully mobile-friendly layout.

## Structure

```
portfolio/
├── index.html        # Page markup & content
├── css/styles.css    # Design tokens, layout, theming
└── js/main.js        # Theme toggle, nav, scroll animations
```

## Editing your content

- **Projects:** edit the cards in the `#work` section of `index.html`. Two are placeholder
  case studies — swap in your real design work (title, tags, description, link).
- **Expertise / Tools:** update the `#expertise` section.
- **Contact:** the email and GitHub links live in the `#contact` section.

## Run locally

Just open `index.html` in a browser — no build step required.

## Deploy (free) with GitHub Pages

1. Push to GitHub (already done).
2. Repo **Settings → Pages → Source: `main` / root**.
3. Your site goes live at `https://schaiganfarooq.github.io/Portfolio/`.
